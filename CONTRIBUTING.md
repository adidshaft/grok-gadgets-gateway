# Contributing

Install uv and Python 3.11+, run `uv sync --locked`, then `uv run pytest` and `uv run ruff check .`. Work on a short-lived feature branch from main. Describe the behavior and tests in your PR; include a local issue reference until GitHub publication is approved. Protocol changes need fixtures and SDK compatibility review.

Shared code of conduct, security and release policies live in the sibling [project hub](../grok-gadgets/README.md). Repository owner and GitHub CODEOWNERS are pending publication; no fictitious maintainer identity is configured.
