# Security

This alpha binds device TCP only to loopback. It is single-user software, not a public hosted service. Do not expose its device port or MCP stdio through a tunnel. Distinct device secrets are configured outside Git.

Private vulnerability reporting contact is pending publication. Until a real private contact is approved, do not publish secrets or exploit details in an issue; contact the project maintainer through the existing private conversation. Public reports may describe non-sensitive reproducible defects.
