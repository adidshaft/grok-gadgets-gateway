# Always-on gateway and a stable device name — owner's kit, 12–13 October 2026

The owner ran these checks on their Mac with the ESP32-S3 OLED kit, at home. The owner observed
the OLED. The gateway request log (`~/Library/Logs/grok-gadgets/requests.jsonl`) recorded each
event. Times are UTC. This record covers one Mac, one router and one kit. Linux systemd was not
tested on a real host (hub [#22](https://github.com/adidshaft/grok-gadgets/issues/22)).

The design is hub [ADR 006](https://github.com/adidshaft/grok-gadgets/blob/main/docs/decisions/006-always-on-gateway.md).

## The slow start in check 5

Warm, the gateway starts in 0.37 s. A stack sample of the slow start showed Python reading module
files at about 2% CPU. The agent had `ProcessType = Background`, which macOS throttles. Gateway
[#115](https://github.com/adidshaft/grok-gadgets-gateway/issues/115) changes it to `Standard`. The
effect of that change after a restart is not yet observed.
